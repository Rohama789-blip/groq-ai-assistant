# 🤖 Groq AI Assistant

A modern AI-powered web assistant built with **Flask** and **Groq API**.

The application provides two chat modes:

- 💬 **Basic Chat** — General AI conversation
- 📚 **RAG Chat** — Answers questions using a provided knowledge document

The project includes a professional dark-themed interface with a responsive design.

---

## ✨ Features

### 💬 Basic AI Chat
Ask general questions and receive intelligent AI-powered responses.

### 📚 RAG Chat
Ask questions about the information stored inside:
